# 开发路线

favkeep 面向个人自托管的单管理员实例。当前源码提供 B 站、抖音和小红书归档，以及本地 MP4、分 P、观看进度与继续观看；具体支持范围和限制以[项目首页](https://github.com/YangChen-mechanical/favkeep)及平台说明为准。

## 当前目标

- 保持已有媒体路径、来源基线、平台凭据和观看记录的升级兼容。
- 完善首次安装、异常恢复和手机端观看，持续验证真实平台的登录与自动归档。
- 保持平台协议和同步规则独立，复用已有认证、媒体访问与资源限制。

## 待办

- 修复 `--douyin-import-session` 的 TLS 初始化顺序问题；修复前使用网页扫码。
- 完善页面防嵌入响应头，评估登录失败全局限速的影响，完成公网 HTTPS 与反向代理安全验收。
- 在声明支持的目标设备上验证升级、配套回退、实际播放和长期自动调度。
- 发布二进制或容器前，验证目标平台、运行依赖和分发许可证；当前仍按源码构建交付。

## 范围

暂不扩展多用户、公共分享、AI 推荐、实时转码、完整图文归档、全量历史补下载或通用插件框架。路线不承诺交付日期，未完成项目不视为已支持。
