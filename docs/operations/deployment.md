# 升级、备份与回退

本文是通用操作步骤。首次安装见[快速开始](../quick-start.md)，开发环境与检查命令见[开发说明](../development/README.md)。不要把其他实例的数据库、管理员、平台凭据或媒体清单复制到自己的正式实例。

## 升级前

1. 记录当前源码提交、程序或镜像摘要、运行用户、Origin、端口、挂载及平台路径。保留旧版本程序和镜像。
2. 在独立目录构建候选版本，先完成前后端检查；不要让源码推送自动更新正式实例。
3. 等待任务空闲。停止写入后冷备整个配置目录，或使用 SQLite 在线 backup 创建一致性副本；不能直接复制活动中的单个主库文件而遗漏 WAL。
4. 配置目录和备份包含凭据、管理员及会话，须限制权限并存放在版本库外。保存与数据库相匹配的程序、配置和 Compose。

## 独立副本演练

使用候选程序和私有数据库副本演练迁移，禁止访问正式库。演练实例禁网、不公开端口；需要旧媒体时只读挂载。

核对迁移前后的作品、分页、全部原字段与路径、观看记录、来源、调度、平台凭据及配置，执行完整性、外键与唯一性检查。再验证管理员登录、匿名拒绝、Origin/CSRF、媒体 HEAD/Range、封面和播放。不能仅凭启动成功或总数量相同通过演练。

默认停用新增平台来源，不将脱敏后的配置响应直接覆盖完整配置。媒体目录与现有 B 站路径的兼容方式见[媒体目录](media-paths.md)。

## 一次性复制到新目录

程序和 crate 已统一使用 `favkeep`，不提供 `bili-sync-rs` 启动入口。停止旧实例后，使用新程序执行一次：

```sh
favkeep --migrate-config-from /absolute/old-config --config-dir /absolute/new-config
```

Windows 使用 `favkeep.exe` 和 Windows 绝对路径。源、目标均须显式指定；目标必须不存在或为空，不能与源相同或互相嵌套，路径不得包含符号链接或 Windows 重解析点。迁移不需要 FFmpeg、网页 Origin 或网络，不启动平台任务。目标已有数据时拒绝覆盖，失败返回非零退出码。

复制内容为 SQLite 一致性快照，以及存在的 `auth-setup.secret`、`douyin/auth.json`、`douyin/login-state.json`、`xiaohongshu/auth.json`。发布目标目录前检查数据库完整性、外键、全部表数据和凭据文件。原数据保留，不在原库执行结构升级。

视频、封面、字幕和 NFO 不移动，数据库中已有媒体路径与下载目录不改写。旧目录内的媒体仍需要保留、可读并维持原挂载路径；旧目录不能整体当作可删除的备份。复制后重新启用任务前确认路径可写、磁盘空间足够。

默认配置目录改为系统配置位置下的 `favkeep`。如果新目录没有数据库而旧默认目录 `bili-sync` 有数据库，启动会提示先迁移。迁移到其他位置时，启动仍须明确指定新目录，例如：

```sh
favkeep --config-dir /absolute/new-config --app-origin https://favkeep.example.com
```

启动脚本、服务配置和容器挂载同时改用新程序名与新目录。`FAVKEEP_CONFIG_DIR`、`FAVKEEP_MEDIA_ROOT`、`FAVKEEP_FFMPEG_PATH` 优先于旧 `BILI_SYNC_*` 别名，命令行优先于两者；旧变量值中的目录不会自动转换。`RUST_LOG` 中旧 `bili_sync` 日志目标继续兼容。

新旧目录同时存在是正常状态。新程序的新增观看记录和配置只写新目录，不会回写旧库；回退前保存新目录，按下述规则成组恢复。

## 正式切换

1. 确认正式任务空闲，停止旧服务，生成最后一组一致性备份并验证可读。
2. 涉及本次命名切换时先执行上述一次性复制，再用已演练的候选、新配置目录和原媒体挂载启动，保留原运行用户与认证配置。后续普通升级使用现有目录；已有数据库会执行尚未应用的结构迁移。
3. 检查登录、旧媒体数量与原路径、播放、声音、拖动、续播、任务状态及新平台目录。容器 healthy 不代表业务验收通过。
4. 通过网页验证本人平台身份后才启用来源。首次基线与历史下载资格按各平台规则处理；不迁入测试历史、媒体或观看记录。
5. 观察真实自动调度、重复扫描及重启恢复，保留旧程序、完整备份和失败日志。未通过的项目单独记录，不能沿用旧轮次的结果代替本轮验证。

## 成组回退

遇启动、迁移、旧数据或播放异常，先停止新程序，保存新库、媒体和日志，再恢复相匹配的旧程序、数据库目录、配置与凭据。旧程序不得连接已升级数据库。

恢复备份可能恢复旧会话，首次启动前须按[认证恢复规则](authentication.md)撤销会话。回退只恢复到备份时间点；保留升级后新增的文件和数据库，核对新索引与观看记录，不删除新媒体。

重新核对挂载、登录、媒体和调度。没有通过副本演练或备份验证时，不进入正式切换。
